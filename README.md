# Sistem PKG Guru Al-Ghozali — Modern

Aplikasi Streamlit dengan logo resmi Al-Ghozali dan database spreadsheet.

## Navigasi

Setiap halaman memiliki tombol **← Kembali ke Dashboard** di bagian atas dan sidebar. Menu aktif juga dapat dipilih dari navigasi sidebar.

## Menjalankan

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m streamlit run app.py
```
